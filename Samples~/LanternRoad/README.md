# The Lantern Road sample

`the-lantern-road.unity.json` is the Unity export of Storyloom's built-in example. Two ways to use it:

1. **Kit** — Window ▸ Storyloom ▸ Import story JSON… → pick this file → Create placeholder prefabs → Create Stardew-style scene → Play.
2. **Runtime only** — put the JSON in a `Resources` folder, add `StoryloomExamplePlayer` to a Canvas with a title/speaker/body Text, a RawImage, an options parent and a Button prefab, and press Play.
